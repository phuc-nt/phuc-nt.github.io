Privacy Policy — cloud agent

Last updated: 2026-10-29

"cloud agent" is a personal assistant used only by the owner of this site, on the owner's own Google account. It is not offered to anyone else.

What it reads

With the owner's consent it reads Gmail, Google Calendar, Google Tasks, Google Drive, Google Docs, Google Sheets and Google Contacts (read-only access), and it creates, writes and deletes only the Google Drive files it creates itself (encrypted backups).

How the data is used

The data is used only to give the owner summaries, reminders and records the owner asked for. It is not sold, not used for advertising, and not shared with anyone. The use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where it is kept

The sign-in is kept as an encrypted secret in the owner's own cloud account; what the assistant derives from the data stays in the owner's own storage there.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
